# Lily（Lily）UI/UX 设计规范 v1.0

> 本文是 Lily 全量界面的设计基线。开发按本文实现，评审按本文验收。
> 所有数值都可直接落到 `DesignTokens.kt`，不出现「看着调」的表述。

---

## 0. 范围与界面清单

产品内核：**人机情感关系**。不是工具，不是配置后台。
品牌语义：百合——柔软、洁净、亲密，但根源带毒。落到界面是「温柔的克制 + 极轻的暗涌」，不是花瓣堆砌，也不是暗黑风。

全量界面 **24 个**，分四层：

| 层级 | 界面 | 代码 |
|---|---|---|
| 一级 · 底栏 3 Tab | 会话列表、动态、我的 | `ConversationListScreen` / `FeedScreen` / `SettingsScreen` |
| 二级 · 会话内 | 聊天、通话、看图、通话详情弹层 | `ChatScreen` / `CallScreen` / `ImageViewer` / `CallDetailDialog` |
| 二级 · 我的 | 我的资料、主题、聊天背景、角色发图、对话、存储、模型、技能、外部服务、安全 | `MyProfileScreen` / `AppearanceScreen` / `ChatBackgroundScreen` / `ImageSettingsScreen` / `DialogueScreen` / `StorageScreen` / `ModelsScreen` / `SkillsScreen` / `McpScreen` / `SafetyScreen` |
| 二级 · 角色 | 人设、声音克隆、陪伴、关系、记忆、梦境、通话记录 | `PersonaScreen` / `VoiceCloneScreen` / `CompanionshipScreen` / `RelationshipScreen` / `MemoryScreen` / `DreamScreen` / `CallRecordsScreen` |

附属组件：输入区（`ComposerPanels`）、头像（`PortraitCard`）、品牌字标（`LilyMark`）。

导航规则（现状已正确，保留）：
- 底栏只在三个一级页出现；单会话、角色编辑、我的二级页一律收起。
- 键盘弹起时底栏隐藏，内容不跳格。
- 页面切换统一「淡入 + 上移 14dp」，`Motion.base` 180ms。

## 1. 设计审计

### P0 · 致命（不做就等于没设计）

**1.1 「我的」变成了设置后台，情感主体被埋**
现状：首屏是 6 行等权重的「未填」资料项（感情状态/生活偏好/外貌特征/性格设定/语气设定/经历补充），恋人卡夹在中间，往下是 6 张同尺寸方块卡。
问题：用户每天想看的是「她」，不是填空。等权重的行 = 没有层级。
修法：见 §9.3 逐页规范——恋人卡升为「关系主卡」置顶，未填项收敛为「待完善」单行，退出首屏。

**1.2 暗色层级靠猜**
现状：`bg #0E0C12` → `surface #211B29` → `surfaceLow #272031`，三段相邻差 ΔL 只有 2–3 个百分点，卡片轮廓在真机上发糊（11/24 真机截图确认）。
修法：建立 4 级明度栈 + 1dp 顶部高光代替阴影，见 §3.4。

**1.3 品牌语义断层**
现状：淡紫是对的，但页面没有一处表达「关系」——没有时间感、没有私密感、没有危险暗示。
修法：三处固定植入（关系天数、仅你们可见、极低透明度百合暗纹），见 §2.3。

### P1 · 严重

**2.1 色彩族系失守**
- `online = #5F8C6E` / `#7FA88C` 是绿色，而同一行的注释写着「柔紫粉，跟主色同族」——**注释与取值矛盾**，说明改动没落地或回滚了。真机截图看到的是紫粉点，源码是绿色，两边不一致，必须先统一。
- `callHangup = #9C5A66` 豆沙红、`danger = #A64B58` 砖红，都跳出了紫族。通话页一亮一红两个圆钮，是整屏最艳的东西，抢掉「她」的主体地位。

**2.2 组件风格分裂**
- 底栏：中间是凸起的实心紫圆钮，两侧是线框图标 —— 三种视觉语言同框。
- 聊天背景页：两个主胶囊按钮权重打架，未选中态在白底上对比不足。
- 滑块：左侧深色竖条读起来像刻度尺，不像可拖控件。

**2.3 状态覆盖缺失**
几乎没有为空态、加载中、加载失败、离线、长文本、图片加载失败、无权限设计过。这些状态在真实使用中占相当比例，缺了就显得「没做完」。

### P2 · 打磨

- 输入区麦克风独立圆钮与输入框基线不对齐。
- 「在一起 3 天」已在 11/24 版本独立高亮（正确），但同一行仍混入过操作提示，需保持纯情绪信息。
- 未接到结果页用冷深灰，不属于紫夜色系。
- 暗色资料页底部「关于你」被底栏截断，缺底部安全间距。
- 动态页红心用豆沙红，与全站紫族不一致。

## 2. 设计语言

### 2.1 四条原则

**A. 关系优先于功能。**
每个一级页必须有一个「情感锚点」在首屏、且视觉权重最高：会话列表是她的状态，聊天是关系天数，动态是「仅你们可见」，我的是关系主卡。设置项永远退到次级。

**B. 温柔来自留白与低饱和，不来自装饰。**
禁止大面积渐变、禁止满屏花瓣、禁止立体高光。氛围靠三样：低饱和紫、大间距、极淡纹理（≤4% 不透明度）。

**C. 每个屏只有一个视觉主角。**
一屏之内，主色实心元素 ≤ 1 个。两个实心紫钮同框即为失败。

**D. 暗涌只做暗示，不做表达。**
「带毒」体现在：暗纹几乎看不见、关系天数会在特定节点加深一档、文案克制。绝不出现骷髅、荆棘、血红、警告图标。

### 2.2 三条硬规则

1. **紫族守恒**：除「错误/危险」外，所有彩色元素必须落在紫族色相 280°±25°。绿、蓝、橙一律不出现在 UI 控件上（图片内容除外）。
2. **单主色**：一屏内 `accent` 实心面积不超过屏宽 × 1.2（约一个胶囊按钮）。其余用 `accentSoft` / `accentOnSoft`。
3. **情绪信息不承载操作**：「在一起 N 天」「仅你们可见」「她现在：平静」这类文字所在行，不允许出现箭头、按钮、可点提示。

### 2.3 三处固定品牌植入

| 位置 | 内容 | 规格 |
|---|---|---|
| 聊天顶栏 | 名字 + `LilyMark` | 字标高 18dp，与名字间距 8dp，颜色 `accent` |
| 动态卡 | 「第 N 天 · 只有你们两个人看得到」 | `label` 档 11.5sp，`accentOnSoft` |
| 聊天背景 | 隐百合暗纹 | 三瓣线稿，不透明度 3.2%，平铺间距 260dp，禁止更浓 |

## 3. 色彩系统

### 3.1 Token 用途表（亮色）

| Token | 值 | 用途 | 对比度要求 |
|---|---|---|---|
| `bg` | `#F7F4FA` | 页面底 | — |
| `surface` | `#FEFCFF` | 底栏、顶栏、输入区 | — |
| `surfaceLow` | `#F3EEF9` | 卡片默认底 | — |
| `surface2` | `#EFE9F6` | 次级块、未选中胶囊 | — |
| `ink` | `#2B2733` | 标题、正文主 | ≥ 12:1 on bg |
| `ink2` | `#57515F` | 次要文字、值 | ≥ 7:1 |
| `ink3` | `#736C7C` | 时间、来源、提示 | ≥ 4.5:1（硬要求） |
| `line` | `#E7E1F0` | 分割线（1dp） | 非文字 |
| `line2` | `#D5CCE2` | 强分割、未选中描边 | 非文字 |
| `accent` | `#6E4D8F` | 主色：选中态、主按钮、字标 | 白字 6.7:1 ✓ |
| `accentInk` | `#FFFFFF` | 主色上的字 | — |
| `accentSoft` | `#EFE6F8` | 主色浅底（标签、角标） | — |
| `accentOnSoft` | `#553976` | 浅底上的字 | ≥ 7:1 ✓ |
| `bubbleUser` | `#E3D8F3` | 我的气泡 | — |
| `bubbleAgent` | `#FBF8FF` | 她的气泡 | — |

### 3.2 需修正的三处（本批必须改）

| Token | 现值 | 改为 | 理由 |
|---|---|---|---|
| `online` | `#5F8C6E`（绿） | **亮 `#B07FA8` / 暗 `#C89AC4`** | 与紫族守恒，且注释早已声明柔紫粉；作为状态点图形对比 ≥3:1 |
| `callHangup` | `#9C5A66` | **亮 `#8E5A72` / 暗 `#B0708C`** | 收进紫族（偏梅子），降饱和，深底不刺眼 |
| `danger` | `#A64B58` | **亮 `#A24F6B` / 暗 `#E093AC`** | 保留「错」的信号，但色相靠向紫红，不与品牌打架 |

同时修正 `DesignTokens.kt` 中 `online` 上方注释与实际值不一致的问题——**以本文为准，值改成紫粉后注释与值同源**。

### 3.3 语义色使用边界

- `accent`：选中 Tab、主按钮、字标、关键数值（关系天数）。
- `accentSoft`：标签底、头像角标底、选中胶囊底。
- `danger`：仅用于「失败/危险操作」，一屏最多出现一次。
- `mood`：情绪标签（她现在：平静）。**不得用于按钮**。
- `callAccept` / `callHangup`：仅通话页。

### 3.4 暗色明度栈（修正 P0-1.2）

现状三段差太小。改为四级栈，相邻 ΔL ≥ 4 个百分点：

| 级 | Token | 新值 | 用途 |
|---|---|---|---|
| L0 | `bg` | `#0B0910` | 页面底（再压深一档） |
| L1 | `surface` | `#1C1624` | 底栏、顶栏、输入区 |
| L2 | `surfaceLow` | `#262030` | 卡片默认 |
| L3 | `surface2` | `#322A3E` | 浮起块、未选中胶囊、弹层 |

暗色 **不用阴影立边界**，用 `1dp` 顶部内高光：`Color(0x0FFFFFFF)`（白 6%），只加卡片顶边。理由：低亮度下阴影不可见，徒增渲染成本。

亮色反向：**不用高光**，只用 `Elevation.card = 2dp` 极弱阴影 + `surfaceLow` 与 `bg` 的明度差。

### 3.5 一屏一个主色（落地检查）

| 界面 | 允许的实心主色元素 |
|---|---|
| 会话列表 | 新建角色按钮（1 个） |
| 聊天 | 无实心主色；发送钮用 `accent` 圆形，唯一 |
| 我的 | 关系主卡左侧色条（细，不算实心块） |
| 通话 | 接听钮（1 个）；挂断用 `callHangup` |
| 聊天背景 | 选中的胶囊（1 个） |
| 其他设置页 | 选中项（1 个） |

## 4. 排版系统

### 4.1 字阶与用途

| 档 | 字号/行高 | 用途 | 字重 |
|---|---|---|---|
| `display` | 28 / 36 | 一级页标题（动态、我的） | 600 |
| `title` | 22 / 30 | 二级页标题（设置子页、角色页） | 600 |
| `headline` | 17 / 26 | 卡片主标题、角色名 | 600 |
| `body` | 15 / 24 | 正文、聊天气泡、设置行标签 | 400 |
| `bodySmall` | 13 / 20 | 副标题、说明、值列 | 400 |
| `label` | 11.5 / 16 | 分组标题、标签、时间 | 500 |
| `micro` | 10.5 / 15 | 角标数字、极次要说明 | 500 |

### 4.2 规则

- 中文不设字距（letter-spacing = 0）；数字与拉丁文同样为 0，避免中英混排松动。
- 一段文字最多两级：`headline` + `bodySmall`。出现第三级就是层级失控。
- 值列（设置行右侧）用 `bodySmall` + `ink2`，非 `ink`——值永远弱于标签。
- 关系天数用 `headline` + `accent` + 600；它是数值型情感信息，允许破格放大。
- 长文本：正文单行超 2 行时，气泡内行高从 24 收到 22（视觉补偿），代码用同一个 `TextStyle` 派生，不新增全局档。

### 4.3 禁止

- 禁止 `ink` 以下再出现第 4 种文字色；所有弱化只能走 `ink2` → `ink3`。
- 禁止一屏内出现 3 种以上字号（`display` + `body` + `label` 已足够）。
- 禁止中文使用 300 及以下字重（安卓渲染会发虚）。

## 5. 空间与栅格

### 5.1 刻度

`4 / 8 / 10 / 12 / 16 / 20 / 28`（`xs / sm / md / lg / xl / page / block`）

### 5.2 固定值

| 项 | 值 |
|---|---|
| 页面左右边距 | 20dp（`Space.page`） |
| 卡片内边距 | 16dp 水平 / 14dp 垂直 |
| 卡片之间 | 10dp |
| 分组之间 | 28dp（`Space.block`） |
| 分组标题与组内首行 | 8dp |
| 列表行最小高 | 52dp（单行）/ 64dp（双行） |
| 底栏高 | 54dp + 安全区 |
| 聊天内容左右边距 | 16dp |
| 气泡之间 | 10dp，同人连发 4dp |
| 顶栏高 | 56dp |

### 5.3 栅格

单列流式。卡片不并排（现状「亮暗与背景 / 记忆」两张并排方块卡在真机文字被压到 2 行，是排版事故；改为单列横向卡，见 §9.3）。

唯一例外：会话列表的多角色头像列表可为横向。

## 6. 形状与层次

### 6.1 圆角语义

| 用途 | 值 |
|---|---|
| 大卡片、容器 | 20dp（`Radius.lg`） |
| 中卡、分组卡内块 | 14dp（`Radius.md`） |
| 小件：标签、角标、输入框 | 10dp（`Radius.sm`） |
| 文字气泡 | 18dp，尾角 6dp |
| 语音气泡 | 22dp，尾角 8dp（更圆 = 更软） |
| 弹层 / 底部面板 | 28dp（仅上两角） |
| 胶囊按钮 | 999dp |

规则：**同一屏内圆角最多两档**。小件不许用 20dp，大卡不许用 10dp。

### 6.2 阴影

只有两档，且只在亮色用：
- `Elevation.card = 2dp`：卡片
- `Elevation.floating = 3dp`：底栏、悬浮「回到底部」

暗色：只用 1dp 顶部内高光（§3.4），不用阴影。

### 6.3 描边

- 默认 **不描边**（去掉生硬黑框是已确认的方向）。
- 允许的唯一描边：未选中胶囊 / 未选中单选，`1dp line2`。
- 分割线 `1dp line`，且优先用间距分层代替分割线。

## 7. 图标

- 尺寸四档：`16 / 18 / 20 / 24`（`sm / md / lg / nav`）。
- 线宽统一 1.5dp 视觉重量：同一屏内的图标必须同档同线宽。
- **禁止混用**：实心图标与线框图标不得在同一组控件里并排出现（当前底栏正是此问题）。
- 底栏三项：选中实心 + 未选中线框是允许的（同尺寸同基线），但**不可**再加凸起圆形底。
- 触控热区 ≥ 44dp，即使图标 18dp。
